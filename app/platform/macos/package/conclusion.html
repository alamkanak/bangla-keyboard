✅ Bangla Keyboard installed successfully!

Step 1: If macOS asks permission to add "Bangla Keyboard" as an input source, click "Allow".
Step 2: Log out and log back in for macOS to fully activate the input method. (Apple menu → Log Out)
Step 3: After logging back in, Bangla Keyboard will open a short setup wizard to help you choose a layout and try typing in Bangla.
Note: If Bangla Keyboard doesn't appear after logging back in, open System Settings → Keyboard → Input Sources → Edit, click "+", find "Bangla" → "Bangla Keyboard" and add it manually.
